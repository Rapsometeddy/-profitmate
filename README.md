# ProfitMate 💰

**ProfitMate** is a lightweight, mobile-first money and micro-business tracker by **Rapsometeddy**.

## Original purpose

The project was created to help turn the **R0 → R1k → R10k/month** goal into something measurable: record income, control expenses, track profit, and set a target.

## Current MVP

- Income and expense tracking
- Automatic balance/profit calculation
- Monthly target with progress bar
- Recent transaction history
- JSON data export
- Local-first storage using the browser
- Mobile-friendly interface
- No API key required
- No database required for the MVP

## Roadmap

1. Supabase sync + authentication
2. Dashboard charts
3. Multiple income streams / business projects
4. Profit goals and monthly reports
5. Opportunity / deal tracker
6. PWA install support
7. Telegram integration
8. Optional AI money insights

> ProfitMate is a record-keeping and planning tool, not financial advice.
