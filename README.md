# ProfitMate 💰

ProfitMate is Rapsometeddy's mobile-first personal money and micro-business tracker.

## Purpose
Turn the R0 → R1k → R10k/month goal into measurable actions: record income, control expenses, track profit, and set targets.

## Current features
- Income and expense tracking
- Profit/balance dashboard
- Monthly target and progress
- Recent activity
- JSON export
- Local-first storage
- Mobile-first UI
- Supabase cloud schema with Row Level Security

## Supabase project
The backend schema is provisioned in the connected Rapsometeddy Supabase project. The current MVP keeps local storage as the fallback so the app works without login.

## Roadmap
- Supabase Auth + cloud sync
- Charts and monthly reports
- Multiple business/project wallets
- Opportunity/deal tracker
- Telegram companion
- Optional AI insights

ProfitMate is a planning and record-keeping tool, not financial advice.
